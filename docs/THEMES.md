# Темы MUSE

Тема — это папка (или .zip с ней), в которой лежит `theme.json`. По желанию к нему можно добавить ещё два файла:

- **свой стиль** (`.css`) — меняет внешний вид чего угодно в MUSE;
- **свой фон** (`.frag`) — шейдер WebGL, который рисует фон за текстом.

Установить тему: **Настройки → Оформление → Темы → Установить тему…**. Выберите `.zip` или `theme.json`, и тема сразу применится. Готовая тема лежит в [`docs/themes/aurora`](themes/aurora), а архив с ней — [`aurora.zip`](themes/aurora.zip).

Свою тему проще всего начать прямо в MUSE: настройте оформление как нравится и нажмите **«Сохранить оформление как тему»**. Получится `.zip` с готовым `theme.json`. Распакуйте его, допишите стиль или фон, если хочется, и упакуйте обратно.

## theme.json

```json
{
  "muse": 1,
  "name": "Северное сияние",
  "author": "MUSE",
  "version": "1.0",
  "description": "Ленты цветов обложки, которые медленно плывут вверх",
  "colors": ["#5ef2c4", "#0b1726"],

  "main": {
    "background": "theme",
    "bgSaturation": 1.3,
    "lyrics": { "accent": "#5ef2c4", "glow": 1.6, "fontWeight": 800 }
  },
  "widget": {
    "background": "tint",
    "glass": "beauty",
    "frost": 0.35,
    "radius": 20,
    "lyrics": { "accent": "#5ef2c4" }
  },
  "wallpaper": {
    "background": "theme",
    "dim": 0.1,
    "lyrics": { "accent": "#5ef2c4", "glow": 1.4 }
  },

  "css": "style.css",
  "shader": "background.frag"
}
```

| Поле | Что это |
|---|---|
| `muse` | Версия формата, сейчас `1`. Тему более нового формата MUSE откажется ставить и попросит обновиться. |
| `name` | Название, обязательно (до 60 символов). Тема с таким же названием при установке обновляется. |
| `author`, `version`, `description` | Необязательные подписи на карточке темы. |
| `colors` | Два цвета `#rrggbb` для карточки темы. |
| `main`, `widget`, `wallpaper` | Оформление главного окна, виджета и живых обоев. Поверхность, которой нет в теме, не меняется. |
| `css`, `shader` | Имена файлов внутри папки темы. |

Тема меняет только внешний вид. **Размер текста, положение активной строки и выравнивание** у каждой поверхности остаются те, что выбрал человек. Поле, которого нет в теме, возвращается к значению по умолчанию, поэтому тема у всех выглядит одинаково. Незнакомые поля и значения MUSE пропускает, а числа приводит к допустимым границам.

### Текст (`lyrics` внутри любой поверхности)

| Поле | Значения |
|---|---|
| `font` | `inter`, `segoe`, `serif`, `rounded`, `mono` |
| `fontWeight` | 300–900 |
| `lineSpacing` | 0.3–2.4 |
| `accent` | цвет подсветки: `auto` (цвет текста), `cover` (из обложки) или `#rrggbb` |
| `unsung` | яркость неспетых слов и неактивных строк, 0.04–0.9 |
| `blur` | размытие соседних строк, 0–2.5 |
| `glow` | свечение, 0–2.5 |
| `fill` | `smooth` (плавная заливка), `word` (по словам), `line` (строкой) |
| `emphasis` | свечение долгих слов, `true` / `false` |
| `scaleInactive` | уменьшать неактивные строки, `true` / `false` |
| `motion` | `soft`, `normal`, `snappy` |
| `wave` | задержка волны между строками, 0–110 мс |

### Фон (`main` и `wallpaper`)

| Поле | Значения |
|---|---|
| `background` | `gradient` (цвета обложки), `animated` (живая обложка), `static`, `solid` (цвет), `theme` (свой шейдер темы) |
| `bgColor` | цвет для `solid`, `#rrggbb` |
| `bgBrightness` | 0.3–1.8 |
| `bgSaturation` | 0–2 |
| `bgSpeed` | скорость движения, 0–3 |
| `bgBeat` | реагировать на бас, `true` / `false` |

У живых обоев есть ещё `dim` — затемнение, 0–0.7.

### Виджет (`widget`)

| Поле | Значения |
|---|---|
| `background` | `tint` (стекло), `cover` (обложка), `none` |
| `glass` | `beauty` (размытие рабочего стола) или `fast` (только тонировка) |
| `tint`, `opacity` | цвет подложки `#rrggbb` и её непрозрачность 0–1 |
| `frost` | мутность красивого стекла, 0–1 |
| `radius` | скругление углов, 0–40 |
| `coverOpacity` | яркость обложки на подложке, 0.1–1 |
| `shadow` | тень под текстом, 0–2 |
| `format` | `lines` (несколько строк) или `line` (одна строка с камерой) |
| `wordColor` | цвет текущего слова в одной строке: `auto`, `cover` или `#rrggbb` |
| `restBrightness` | яркость остальных слов в одной строке, 0.06–0.9, или `null` — как у неактивных строк |
| `levels` | эквалайзер в такт, `true` / `false` |

## Свой стиль (`css`)

Стиль подключается во все окна MUSE, пока тема активна. Окна различаются классом на `<html>`: `is-main`, `is-widget`, `is-wallpaper`.

Полезные места:

- `.lx-line` — строка текста, `.lx-line[data-d="0"]` — та, что поётся, `.lx-w` — слово;
- `.lx-label` — подпись части песни, `.lx-sub` — латиница под строкой;
- `.widget-panel` — подложка виджета, `.widget-title`, `.widget-artist`, `.widget-card` — карточка с обложкой, когда нет синхронного текста;
- `.wl-w.is-now` — текущее слово в виджете «одной строкой».

```css
/* Активная строка чуть разреженнее и с мягкой тенью. */
.lx-line[data-d="0"] .lx-text {
  letter-spacing: 0.01em;
  text-shadow: 0 0 40px rgba(94, 242, 196, 0.25);
}
```

Стиль не может ничего загрузить из интернета: `@import` вырезается, а `url(...)` работает только с `data:` (картинку или шрифт можно встроить прямо в файл). Размер файла — до 256 КБ. Внутренние классы MUSE могут меняться между версиями, поэтому держитесь мест из списка выше.

## Свой фон (`shader`)

Это фрагментный шейдер GLSL ES 1.0 (WebGL 1). Чтобы он заработал, в теме нужно указать `"background": "theme"`, а человек может выбрать его и сам: **Фон → Из темы**. Если шейдер не собрался, MUSE показывает вместо него цвета обложки и пишет ошибку под выбором фона.

Всё ниже уже объявлено, его не нужно писать заново:

| Имя | Что это |
|---|---|
| `vUv` | координата пикселя, 0–1 |
| `uTime` | время в секундах, уже с учётом скорости из настроек |
| `uAspect` | ширина / высота окна |
| `vec3 cover(vec2 uv)` | цвет обложки в точке (обложка уже размыта до цветовых пятен, за краями зеркалится) |
| `uBeat` | удар баса, 0–1: на удар быстро растёт и за ~0,3 с спадает |
| `uMid` | средняя яркость обложки, 0–1 |
| `uPhA` | четыре случайных числа, свои у каждого окна и каждой песни |
| `uTheme` | 0 — тёмная тема, 1 — светлая |
| `vec3 tone(vec3 col)` | подгоняет цвет под тему, яркость и насыщенность из настроек и добавляет виньетку; лучше прогонять через него итоговый цвет |

```glsl
void main() {
  vec2 p = vUv - 0.5;
  p.x *= uAspect;
  vec3 col = cover(vUv + 0.05 * vec2(sin(uTime * 0.2 + p.y * 3.0), cos(uTime * 0.17 + p.x * 3.0)));
  col *= 1.0 - 0.3 * uBeat;
  gl_FragColor = vec4(tone(col), 1.0);
}
```

Фон рисуется в трети разрешения окна, 24–60 раз в секунду (это зависит от настроек частоты кадров), и замирает в игровом режиме. Тяжёлые циклы и десятки выборок `cover()` на пиксель всё равно скажутся на видеокарте, особенно на живых обоях 4K. Размер файла — до 64 КБ.

## Безопасность

Тема — это данные, а не программа. В ней нет кода, который выполняется на компьютере: стиль только оформляет, а шейдер работает на видеокарте внутри песочницы WebGL. Файлы темы не могут выйти за пределы её папки.
